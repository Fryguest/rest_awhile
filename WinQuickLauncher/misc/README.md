# WinQuickLauncher

Windows / AutoHotkey v2。运行 `run.ahk`，按 Ctrl+1 显示／隐藏。

## 界面

保留原启动器的布局、配色、透明度、图标大小、间距、齿轮入口和操作方式。
备忘录只使用原居中图标列表左侧的空白区域，不移动、缩放或重命名原内容。

备忘录不设名称或标题，只有筛选、添加按钮和普通列表，没有卡片、口号、进度条或装饰。
左侧宽度不足时不遮挡原启动列表；较窄时只显示事项，其他信息可通过编辑和完成记录查看。

## 备忘录操作

- **添加**：点击列表上方的「添加」。
- **编辑**：双击事项，或右键选择「编辑」。
- **删除**：右键选择「删除」，确认后连同完成记录删除。
- **完成**：勾选事项后选择实际完成日期，默认今天，允许补记，不允许未来日期。
- **撤销完成**：取消勾选，只撤销当前周期的完成记录。
- **完成记录**：右键打开，查看过去周期的完成日期，也可修改本次完成日期。
- **分类**：按「每天／每周／其他周期／单次」筛选，也可按标签筛选；标签完全自定义，多个标签用逗号分隔。

类型只用功能性字眼：

- **重复**：设置下一次刷新时间和间隔（N 天／N 周）。到期后无论完成与否，都恢复为未完成，历史记录保留。
- **单次**：不自动重置，完成后仍保留，可以撤销完成。

刷新间隔为 1～3650 天，下次时间可精确到分钟；每天默认次日零点，每周默认下周一零点，也可自行调整。
周期按原设定时间推进。关闭工具期间漏过的周期，重新启动后补齐，不伪造完成记录。
完成日期精确到日；补记过去日期仍标记当前周期完成，不改变刷新安排。

弹窗中 Enter 或 Ctrl+Enter 保存，Esc 取消。原启动器的 Ctrl+1、Esc 和设置操作不变。

## 数据

独立保存到 `memo-data.tsv`，兼容上一版已有事项和完成记录，不改动启动器配置或录制文件。

- 保存时先写 `.tmp` 再替换正式文件，上一份成功版本保留为 `memo-data.tsv.bak`。
- 保存失败不发布修改；读取失败不覆盖原文件，并暂停编辑。
- 恢复时先退出脚本，备份原文件，再用 `.bak` 替换正式文件并重启。
- 个人数据已加入 `.gitignore`。

`memo.ahk` 负责界面与调度，`memo-core.ahk` 负责数据、周期计算和存储。
`recorder.ahk` 未改动。当前环境只做静态检查，未运行 AutoHotkey。
